# Bella Vista Salon – Appointment Booking Prototype

**Project:** Bella Vista Salon
**Location:** Coral Gables, Florida
**Developer:** Waqar Javed

## 1. Project Overview

Bella Vista Salon is a proposed appointment booking web application for a salon in Coral Gables, Florida. The prototype will help clients view available services and request appointments while allowing salon staff to manage and track bookings.

The project focuses on simplifying appointment scheduling, reducing manual coordination, and improving the experience for both clients and salon staff.

## 2. Project Selection – Option B

I selected Option B: Bella Vista Salon because appointment scheduling is a common business operation that can benefit from a simple web-based solution.

A digital booking system can make it easier for clients to schedule services and help staff organize appointments without depending entirely on phone calls and manual records.

## 3. Problem Statement

Bella Vista Salon currently relies on manual appointment coordination, including phone calls and staff-managed scheduling. This can create scheduling conflicts, communication delays, and difficulties tracking appointments for both clients and salon staff.

Our prototype will provide a web-based appointment booking system where clients can explore salon services and request appointments for their preferred dates and times. Staff will be able to review appointments and confirm, complete, or cancel bookings so that the salon can manage its daily schedule more efficiently and provide a smoother booking experience.

## 4. Target Users and Personas

### Persona 1: Client – Maria Rodriguez

- **Role:** Regular salon customer.
- **Main Goals:** Find salon services, book appointments conveniently, and choose a suitable date and time.
- **Frustrations:** Waiting for phone responses, difficulty finding available appointment times, and uncertainty about booking confirmation.
- **Technology Comfort:** Comfortable using websites and mobile applications.
- **Quote:** "I want to book my salon appointment online without having to call and wait for someone to answer."

### Persona 2: Staff Member – Daniel Martinez

- **Role:** Salon receptionist.
- **Main Goals:** Manage daily appointments, confirm bookings, track completed appointments, and avoid scheduling conflicts.
- **Frustrations:** Managing phone calls while updating appointment records and keeping track of schedule changes.
- **Technology Comfort:** Comfortable using basic computer applications and web-based systems.
- **Quote:** "I need one place where I can see all appointments and keep the daily schedule organized."

## 5. Must-Have Features

The prototype will include the following essential features:

1. **Service Listing:** Display available salon services and descriptions.
2. **Appointment Booking:** Allow clients to select a service, date, and preferred time.
3. **My Appointments:** Allow clients to view their existing appointments.
4. **Appointment Confirmation:** Allow staff to confirm requested bookings.
5. **Staff Calendar:** Provide staff with an overview of scheduled appointments.
6. **Appointment Status Management:** Allow staff to mark appointments as completed or canceled.
7. **Service Administration:** Allow authorized staff to manage salon services.

## 6. Out-of-Scope Features

The following features will not be included in the initial prototype:

1. Online payments and payment gateway integration.
2. SMS and automated email appointment reminders.
3. Native Android or iOS mobile applications.
4. Customer loyalty and rewards programs.
5. Advanced employee payroll and commission management.
6. Third-party calendar integrations.

These exclusions will keep the prototype focused on its primary purpose: demonstrating the essential appointment booking and management workflow.

## 7. Technology Stack

The planned technology stack includes:

- **Programming Language:** Python
- **Web Framework:** Flask
- **Frontend:** HTML, CSS, and Bootstrap
- **Development Environment:** Visual Studio Code
- **Version Control:** Git and GitHub

## 8. Project Objectives

The primary objectives of this prototype are to:

- Demonstrate a basic appointment booking workflow.
- Provide an organized interface for salon clients and staff.
- Practice Python and Flask web application development.
- Apply software prototyping concepts learned in EGN 475.
